# 專案指引 — 高醫醫學女排‧排球訓練紀錄

ASP.NET Core 8 + React 19（Vite + TS）+ PostgreSQL 17 的排球訓練紀錄系統。
完整技術棧、目錄結構與本機開發步驟見專案根目錄 `README.md`；部署見 `DEPLOY.md`。

## 專案名稱與版權

- 本系統正式名稱為「**高醫醫學女排‧排球訓練紀錄**」，所有對外顯示文字（瀏覽器標題、登入頁、側欄品牌名）一律使用此名稱。
- 著作權屬「**陳源和**」所有；登入頁頁尾固定顯示版權聲明，未經授權請勿使用。
- 相關檔案：`volleyballtrainingtracker.client/index.html`（title）、`src/pages/Login.tsx`（標題與頁尾版權）、`src/components/AppLayout.tsx`（側欄／頂欄品牌名，空間有限僅顯示「高醫醫學女排」）。

## 溝通語言

**一律使用繁體中文**回覆與說明，不要使用日文或其他語言。

## 工具使用規則

**不使用 vexp**：不要啟動或呼叫任何 vexp 相關工具（run_pipeline、get_skeleton、index_status、expand_vexp_ref）。

搜尋與探索程式碼請直接使用 Glob、Grep、Read 等內建工具。

## 資料庫

**資料庫為 PostgreSQL 17**。

- 後端：EF Core 8 + `Npgsql.EntityFrameworkCore.PostgreSQL`，provider 為 `UseNpgsql`
- 連線設定在 `appsettings.json` 的 `ConnectionStrings:Default`（Host/Port/Database/Username/Password 格式）
- 結構來源：`VolleyballTrainingTracker.Server/Data/Sql/pg_init.sql`（合併版 DDL，反映 EF 模型最終狀態）
- 識別字一律 PascalCase 並加雙引號（如 `"Users"`），對應 Npgsql 預設行為；手寫 SQL 也必須加引號
- 型別重點：`varchar`、`boolean`、`smallint`、`timestamptz`、`GENERATED BY DEFAULT AS IDENTITY`
- `DateTime` 一律以 UTC 寫入（`timestamptz` 要求 `Kind=Utc`）

## 球員位置規範

位置代碼（存入 DB）與中文顯示名稱如下，所有 UI 一律使用此對應：

| 代碼 | 中文名稱 |
|------|--------|
| OH   | 主攻    |
| OPP  | 副攻    |
| MB   | 攔中    |
| S    | 舉球員  |
| L    | 自由    |

- 相關檔案：`src/pages/Players.tsx`（POSITION_OPTIONS / POSITION_LABELS）、`src/pages/PlayerEdit.tsx`（POSITIONS）
- DB 儲存值仍為英文代碼（OH/OPP/MB/S/L），多個位置以逗號分隔
- 不使用 DS（防守專才）於 UI，SQL constraint 保留但不在 UI 提供

## 響應式並排版面規範

**裝置夠寬時，獨立區塊應並排而非垂直堆疊。**

- breakpoint 以 `xl:`（1280px+）為並排觸發點
- 多個同層 Card / 編輯器：用 `grid grid-cols-1 xl:grid-cols-2 gap-6 items-start`
- 表單（左）＋ 編輯區（右）：用 `xl:grid xl:grid-cols-[2fr_3fr] xl:gap-6 xl:items-start`
- 手機版（預設）保持 `space-y-*` 垂直堆疊，不影響小螢幕
- 已實作範例：`Drills.tsx`（左側清單 / 右側編輯區）
