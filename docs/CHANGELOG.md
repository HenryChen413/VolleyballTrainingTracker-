## [2026-06-12]

### 新增
- **戰術板：戰術畫線**
  - 場地上方新增畫線工具列：**選取／直線／箭頭／自由曲線／橡皮擦**，可畫攻擊、跑位、接球、防守、發球等路線（路線語意以顏色區分）。
  - 線條屬性：6 色色盤（預設紅）、三段粗細（細／中／粗，箭頭大小隨粗細連動）。
  - 編輯：選取模式下點選線條即可整條拖移、拖端點改起終點（直線／箭頭）、變更顏色與粗細；Delete 鍵或「刪除選取」可刪除；「清除全部」一鍵清空（球員站位不受影響）。
  - 圖層隔離：畫線模式時球員完全鎖定不會被誤拖、選取模式時畫線層不攔截球員拖曳；支援滑鼠與觸控。
  - 戰術線草稿與站位一樣依名單來源保存於本機瀏覽器。
- **戰術板（Phase 1）**
  - 新頁面「戰術板」（`/tactics`）：SVG 標準排球場（含球網、攻擊線、前排／後排與 4-3-2／5-6-1 六個輪轉位置錨點）。
  - 名單來源二段式切換：**全部球員**（現役選手）／**友誼賽**／**正式比賽**（選定賽事後顯示該場報名球員）。
  - 點選名單球員自動補位上場（依輪轉序 1→6），或直接拖曳到場上任意位置；場上球員可拖曳移動、拖到另一人身上交換站位、拖回名單區（或雙擊）移出，支援滑鼠與觸控。
  - 站位草稿依名單來源各自保存於本機瀏覽器（localStorage），切換來源不互相覆蓋。
  - 權限：全員可看可編（凡可看儀表板的角色一併開放）。

### 技術
- 既有資料庫請執行增量腳本 `VolleyballTrainingTracker.Server/Data/Sql/2026-06-12_AddTacticsPage.sql` 為各角色補上 `tactics` 頁面；新資料庫由 `seed-roles` 自動帶入。
- 拖曳採原生 Pointer Events（未新增任何套件）；場地座標以 0~1 正規化保存，為 Phase 2「儲存戰術」（jsonb Layout）與後續輪轉模擬預留擴充。
- 戰術線三種線型統一以 SVG `<path>` 渲染（自由曲線取樣＋Douglas-Peucker 簡化＋中點貝茲平滑）；箭頭為顯式三角形（不用 `<marker>`，避免顏色跟隨與匯出相容性問題）；細線選取用隱形加粗命中描邊；幾何計算為純函式並附單元測試（`src/lib/drawing.test.ts`）。所有線條變更收斂於單一入口，為 Undo/Redo 與戰術播放預留接縫；草稿存於獨立 key（`vbtt-tactics-drawings`），與站位草稿分離（對齊未來 DB Layout／Drawings 分欄設計）。

## [2026-05-22]

### 新增
- **使用者最近登入時間**
  - 登入成功時記錄該次登入時間。
  - 「使用者管理」頁新增 **最近登入** 欄位：以相對時間呈現（如「3 天前」），滑鼠移上可看完整日期時間；從未登入過的帳號顯示「從未登入」。
  - 「最近登入」欄可排序（從未登入者視為最早），並新增 **「僅顯示從未登入者」** 開關（標籤顯示人數），方便找出尚未登入過的帳號。

### 技術
- `Users` 資料表新增 `LastLoginAt`（`timestamptz`、可空、UTC）欄位；增量腳本：`VolleyballTrainingTracker.Server/Data/Sql/2026-05-22_AddUserLastLoginAt.sql`。
- 登入流程改以 EF Core `ExecuteUpdate` 只更新 `LastLoginAt` 單一欄位，刻意不觸發 `SaveChanges` 的 `UpdatedAt` / `UpdatedByUserId` 稽核戳記，避免「登入」被誤記為一次資料更新。

### 移除
- 刪除前端 `volleyballtrainingtracker.client/Schema/` 死檔資料夾（自動匯出產物，內容為早期 SQL Server 殘留、與現行 PostgreSQL 結構不符，且前端未實際引用）。
