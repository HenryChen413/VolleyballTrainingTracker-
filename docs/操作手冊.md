## 1. 系統簡介

「高醫醫學女排‧排球訓練紀錄」是一套網頁版的球隊管理系統,協助教練團記錄球員名單、每次訓練的內容、比賽戰績,並以圖表呈現球隊整體狀態。

- **使用方式**:用瀏覽器開啟系統網址即可,無須安裝任何軟體。
- **建議瀏覽器**:Chrome、Edge、Safari 等較新版本的瀏覽器。
- **裝置支援**:電腦、平板、手機皆可使用,版面會自動依螢幕大小調整。
- **資料範圍**:本系統管理單一支球隊的資料。

## 2. 登入與登出

### 2.1 登入

1. 開啟系統網址,會看到「登入帳號」畫面。
2. 在 **帳號** 欄位輸入你的帳號(僅限英文與數字,輸入時會自動轉成大寫)。
3. 在 **密碼** 欄位輸入密碼。
4. 按 **登入** 按鈕。
5. 登入成功後會自動進入「儀表板」。

> 若帳號或密碼錯誤,畫面會顯示紅色提示訊息。帳號需由管理員預先建立,無法自行註冊。

### 2.2 自動登出(閒置保護)

為保護資料安全,若 **連續 5 分鐘沒有任何操作**(滑鼠、鍵盤、捲動皆算),系統會自動登出並回到登入頁。重新登入即可繼續使用。

### 2.3 登出

點畫面 **右上角的登出圖示**(向右箭頭),即可手動登出。

## 4. 角色與權限

系統以「角色」決定每位使用者能看到哪些頁面、能做哪些操作。內建三種角色:

| 角色 | 典型對象 | 一般可做的事 |
|------|----------|--------------|
| **Admin** | 系統管理者 | 幾乎所有操作,包含管理使用者與角色 |
| **Coach** | 教練 | 管理選手、訓練紀錄、訓練項目等 |
| **Player** | 球員 | 多為檢視性質,依角色設定而定 |

權限分兩個層次:

1. **頁面權限**:能不能「看到」某個頁面。
2. **編輯權限**:在看得到的頁面裡,能不能「新增 / 修改 / 刪除」。

> **重點**:若某頁你只有「檢視」權限,畫面上的「新增」「編輯」「刪除」按鈕會自動隱藏,你仍可瀏覽內容。

### 超級管理員

帳號 **YUANHE** 為系統的超級管理員:

- 只有 YUANHE 能進行使用者的新增、修改、停用、刪除。
- YUANHE 帳號本身 **永遠不可被停用、刪除或變更角色**。

各功能頁的操作說明中,凡屬「需要編輯權限」的動作都會特別標註。

## 5. 儀表板

儀表板是登入後的首頁,呈現球隊的整體狀態,**只供檢視,不需任何操作**。

內容包含:

- **YouTube 頻道**:點「前往頻道」可開啟球隊影片頻道。
- **關鍵數字**:現役選手人數、本學年度比賽次數、友誼賽次數。
- **訓練分布**:以雷達圖呈現各技術面向的訓練比重。右上角可切換統計區間(近 3 / 6 / 12 個月)。下方卡片列出各分類的訓練動作與次數。
- **戰績總覽**:本學年度各場比賽的名次與勝負明細。
- **近 5 場**:最新 5 個賽事大項目(含友誼賽)。

> 畫面右上角的標籤顯示目前統計的「學年度」。

## 6. 選手

「選手」頁是球隊名單總覽,球員依狀態分成 **現役 / 畢業 / 退隊** 三區(畢業、退隊預設收合,點標題可展開)。

### 6.1 檢視與搜尋

- **搜尋**:在搜尋框輸入姓名、暱稱或背號,清單即時過濾。
- **篩選**:用「位置」「系級」「狀態」下拉,以及「重複號碼」按鈕縮小範圍;已套用的條件會以標籤列出,可逐一清除或「全部清除」。
- **排序**:右上可選擇依背號、姓名、身高、系級排序,並用箭頭鈕切換正序 / 倒序。
- **球隊統計**:頁面上方顯示現役人數、畢業 / 退隊人數,以及各位置人數分布。

### 6.2 比較球員

1. 在球員卡片右上角點 **天秤圖示**(或選取卡片後按空白鍵)將球員加入比較,最多 4 位。
2. 畫面下方出現比較浮動列,選滿 2 位以上後按 **比較**。
3. 彈出視窗以表格並列各球員的背號、位置、身高、系級等資料(身高最高者會被標示)。

### 6.3 匯出名單

點右上 **匯出** 按鈕,可將 **目前篩選結果** 下載成 CSV 檔(可用 Excel 開啟)。

### 6.4 新增選手　*(需選手編輯權限)*

1. 點右上 **新增選手**。
2. 填寫資料:
   - **姓名**(必填)
   - 暱稱(選填,最多 32 字)
   - 背號(1–99)
   - 身高(公分)
   - 生日(選填)
   - 系級(例:110)
   - **位置**(可多選,見[附錄](#14-附錄名詞與代碼對照))
   - 慣用手(左 / 右)
   - 備註
   - **狀態**(現役 / 畢業 / 退隊)
3. 按 **儲存**,完成後回到選手清單。

### 6.5 編輯選手　*(需選手編輯權限)*

點任一球員卡片,或卡片右上的 **鉛筆圖示**,即可進入編輯畫面;修改後按 **儲存**。
編輯畫面上方會顯示「最後更新者」與時間。

### 6.6 永久刪除選手　*(需「永久刪除選手」特殊權限)*

在編輯畫面右下角的 **刪除此選手** 按鈕,會將該球員與其所有相關紀錄 **永久移除,無法復原**,請審慎使用。一般情況建議改用「狀態:退隊 / 畢業」保留歷史資料。

## 7. 訓練紀錄

「訓練紀錄」頁列出每一次訓練的卡片,依日期呈現。

### 7.1 檢視

- 每張卡片顯示日期、地點、訓練項目數量,以及各分類的項目數標籤。
- **點卡片可展開**,查看該次訓練選用的所有訓練項目(依分類分組)。
- 上方可用搜尋框(搜尋地點或備註)與「地點」下拉做篩選。

### 7.2 新增訓練　*(需訓練紀錄編輯權限)*

1. 點右上 **新增訓練**。
2. 填寫:
   - **日期**(必填)
   - 地點
   - **訓練項目**:從項目選擇器勾選本次要進行的項目。
   - 備註
3. 按 **儲存**。

### 7.3 編輯 / 刪除訓練　*(需訓練紀錄編輯權限)*

- 在卡片上點 **鉛筆圖示** 進入編輯;修改後按 **儲存**。
- 編輯畫面右下的 **刪除訓練** 會一併刪除該次訓練所選的項目關聯(不影響「訓練項目」項目庫本身)。

## 8. 比賽紀錄

「比賽紀錄」頁以賽事為單位,記錄每場賽事的對戰結果、出賽名單與比分。

### 8.1 檢視

- 每張賽事卡片顯示日期、學年、賽事類型(比賽 / 友誼賽)、名次、場數、出賽人數,以及一個 **戰績圓環**(勝 / 敗 / 平比例)。
- 若該賽事為 **分隊出賽**,會分別顯示 A 隊、B 隊的名次與戰績。
- **點卡片可展開**,查看出賽名單(依位置分組)與每一場對戰的比分細節(含各局比分)。
- 卡片若附影片連結,點「影片」可另開觀看。
- 上方篩選列可依 **學年**、**類型**(全部 / 比賽 / 友誼賽)以及關鍵字(對手、賽事名稱、地點)過濾。

### 8.2 新增比賽　*(需比賽紀錄編輯權限)*

1. 點右上 **新增比賽**。
2. 填寫賽事基本資料:賽事名稱、日期、類型、地點、影片網址、名次等。
3. 視需要設定是否 **分隊出賽**(A / B 隊)。
4. 加入 **出賽名單**(從球員中挑選)。
5. 逐場登錄 **對戰紀錄**:對手、總比分、各局比分、勝負結果。
6. 按 **儲存**。

### 8.3 編輯 / 刪除比賽　*(需比賽紀錄編輯權限)*

在賽事卡片點 **鉛筆圖示** 進入編輯;刪除動作同樣在編輯畫面內。

## 9. 訓練項目

「訓練項目」是一個 **項目庫**,集中管理所有可在「訓練紀錄」中被選用的訓練動作。項目依分類(基礎、發球、接發球、舉球、攻擊、攔網、防守、體能)分組。

### 9.1 檢視與搜尋

- 用搜尋框搜尋名稱或描述(鍵盤按 `/` 可快速聚焦搜尋框)。
- 點分類標籤可只顯示該分類的項目。
- 打開 **顯示已停用** 開關可一併看到停用中的項目。
- 7 天內新建的項目會標示「新」。

### 9.2 新增項目　*(需訓練項目編輯權限)*

1. 點右上 **新增項目**(鍵盤按 `N` 亦可)。
2. 填寫 **名稱**(必填)、**分類**(必選)、描述。
3. 「啟用中」開關決定此項目是否出現在訓練紀錄的選單中。
4. 按 **儲存**。

### 9.3 編輯、複製、停用　*(需訓練項目編輯權限)*

- **編輯**:點項目或鉛筆圖示。
- **複製**:點 **複製圖示** 會以該項目內容為範本開新項目(名稱自動加「複本」)。
- **快速啟用 / 停用**:直接切換項目列右側的開關。
- **停用**:在編輯畫面點「停用此項目」。停用後 **不會出現在新訓練的選單**,但 **既有歷史紀錄仍保留**。

> 訓練項目採「停用」而非真正刪除,以保護過往訓練紀錄的完整性。

## 10. 我的帳號

「我的帳號」頁讓你管理自己的個人資料與密碼。點頂部列的 **人形圖示** 進入。

### 10.1 基本資料

- 可修改 **Email** 與 **顯示名稱**。
- **帳號無法自行修改**。
- 修改後按 **儲存**。

### 10.2 變更密碼

1. 輸入 **目前密碼**(用於驗證身分)。
2. 輸入 **新密碼**(至少 8 個字)。
3. 再次輸入新密碼確認。
4. 按 **更新密碼**。

## 11. 使用者管理

「使用者管理」頁管理可登入系統的帳號。

> **重要**:只有超級管理員 **YUANHE** 能執行新增 / 編輯 / 停用 / 刪除;其他人即使能看到此頁,也僅能 **檢視清單**。

### 11.1 檢視

- 上方有「總計 / 啟用 / 停用 / Admin」統計卡,點卡片可快速套用對應篩選。
- 可用搜尋(帳號 / 顯示名稱 / Email)、角色、狀態做篩選。
- 表頭可點選切換排序。

### 11.2 新增使用者　*(僅 YUANHE)*

1. 點右上 **新增使用者**。
2. 填寫:
   - **帳號**(必填,僅英數,至少 3 字;`YUANHE` 為保留字不可使用)
   - 顯示名稱、Email
   - **角色**(必選)
   - **密碼**(必填,至少 8 字;畫面會顯示密碼強度)
3. 按 **儲存**。

### 11.3 編輯使用者　*(僅 YUANHE)*

點清單中任一列開啟編輯視窗,可修改顯示名稱、Email、角色;勾選「變更密碼」可重設該使用者的密碼。
**帳號建立後不可變更。**

### 11.4 啟用 / 停用、刪除　*(僅 YUANHE)*

- 用清單列上的 **電源圖示** 啟用 / 停用帳號;停用後該帳號無法登入。
- **垃圾桶圖示** 為刪除,刪除無法復原。
- 將角色變更為 / 自 Admin 時,系統會跳出二次確認。
- 超級管理員 YUANHE、以及「自己正在使用的帳號」會被保護,無法被停用或刪除。

## 12. 角色管理

「角色管理」頁設定每個角色「能看到哪些頁面、能執行哪些動作」。

### 12.1 版面

- **左側**:角色清單,顯示每個角色的使用人數、權限數、頁面數。系統內建角色會標「系統」。
- **右側**:選取角色後的編輯區。

### 12.2 編輯角色

1. 從左側點選一個角色(或按 **+** 新增角色)。
2. 設定 **名稱** 與 **描述**(系統角色名稱不可改)。
3. **可看到的頁面**:點選要開放給此角色的頁面。
4. **編輯權限**:開啟後該角色可對對應資源做新增 / 修改 / 刪除。
5. **特殊權限**:破壞性或系統管理動作(如「永久刪除選手」「使用者管理」「角色管理」),授權前請特別確認。
6. 按 **儲存**。

> - 開啟某項「編輯權限」時,系統會 **自動勾上對應頁面**(沒有頁面權限,編輯權限無從使用)。
> - 「全選 / 全清」可一鍵套用或清除所有頁面與權限。

### 12.3 刪除角色

- 系統內建角色 **不可刪除**。
- 自訂角色若仍有使用者使用,**需先把那些使用者改派到其他角色** 才能刪除。

## 13. 常見問題 FAQ

**Q1. 為什麼我看不到某個選單(例如「使用者」)?**
側邊選單只顯示你的角色被允許的頁面。若需要該頁面,請聯絡管理員調整角色權限。

**Q2. 為什麼頁面上沒有「新增 / 編輯」按鈕?**
代表你只有該頁的檢視權限。需要編輯權限請聯絡管理員。

**Q3. 我突然被登出了。**
系統閒置滿 5 分鐘會自動登出,屬正常的安全保護。重新登入即可。

**Q4. 帳號忘記密碼怎麼辦?**
請聯絡超級管理員 YUANHE,於「使用者管理」中為你重設密碼。

**Q5. 進到「無權限」頁面?**
表示你嘗試開啟的頁面未對你的角色開放。回到儀表板或聯絡管理員。

**Q6. 停用的訓練項目,以前的訓練紀錄會消失嗎?**
不會。停用只是讓項目不再出現在新訓練的選單中,既有歷史紀錄完整保留。

**Q7. 不小心把選手設成「退隊」?**
進入該選手編輯畫面,把「狀態」改回「現役」並儲存即可。

**Q8. 為什麼建議用「退隊 / 畢業」而不是刪除選手?**
「永久刪除」會連同該球員的歷史比賽、訓練紀錄一併移除且無法復原;改狀態則可保留所有歷史資料。

### 14.4 比賽相關名詞

| 名詞 | 說明 |
|------|------|
| 比賽(Official) | 正式賽事,計入戰績總覽 |
| 友誼賽(Friendly) | 練習性質賽事 |
| 分隊出賽 | 同一賽事中球隊分成 A、B 兩隊參賽 |
| 勝 / 敗 / 平 | 單場對戰結果 |
| 名次 | 該賽事的最終排名 |
