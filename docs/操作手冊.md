## 1. 系統簡介

「高醫醫學女排‧排球訓練紀錄」是一套網頁版的球隊管理系統,協助教練團記錄球員名單、每次訓練的內容、比賽戰績,並以圖表呈現球隊整體狀態。

- **使用方式**:用瀏覽器開啟系統網址即可,無須安裝任何軟體。
- **建議瀏覽器**:Chrome、Edge、Safari 等較新版本的瀏覽器。
- **裝置支援**:電腦、平板、手機皆可使用,版面會自動依螢幕大小調整。
- **資料範圍**:本系統管理單一支球隊的資料。

## 2. 登入與登出

### 2.1 登入

1. 開啟系統網址,會看到「登入帳號」畫面。
2. 在 **帳號** 欄位輸入你的帳號(僅限英文與數字,輸入時會自動轉成大寫)。
3. 在 **密碼** 欄位輸入密碼。
4. 按 **登入** 按鈕。
5. 登入成功後會自動進入「儀表板」。

> 若帳號或密碼錯誤,畫面會顯示紅色提示訊息。帳號需由管理員預先建立,無法自行註冊。

### 2.2 自動登出(閒置保護)

為保護資料安全,若 **連續 5 分鐘沒有任何操作**(滑鼠、鍵盤、捲動皆算),系統會自動登出並回到登入頁。重新登入即可繼續使用。

### 2.3 登出

點畫面 **右上角的登出圖示**(向右箭頭),即可手動登出。

## 4. 角色與權限

系統以「角色」決定每位使用者能看到哪些頁面、能做哪些操作。內建三種角色:

| 角色 | 典型對象 | 一般可做的事 |
|------|----------|--------------|
| **Admin** | 系統管理者 | 幾乎所有操作,包含管理使用者與角色 |
| **Coach** | 教練 | 管理選手、訓練紀錄、訓練項目等 |
| **Player** | 球員 | 多為檢視性質,依角色設定而定 |

權限分兩個層次:

1. **頁面權限**:能不能「看到」某個頁面。
2. **編輯權限**:在看得到的頁面裡,能不能「新增 / 修改 / 刪除」。

> **重點**:若某頁你只有「檢視」權限,畫面上的「新增」「編輯」「刪除」按鈕會自動隱藏,你仍可瀏覽內容。

> **例外**:「哭哭榜」採「可看就可編」設計 — 只要看得到該頁就能新增 / 修改 / 刪除,沒有額外的編輯權限門檻(見[第 11 章](#11-哭哭榜))。

### 超級管理員

帳號 **YUANHE** 為系統的超級管理員:

- 只有 YUANHE 能進行使用者的新增、修改、停用、刪除。
- YUANHE 帳號本身 **永遠不可被停用、刪除或變更角色**。

各功能頁的操作說明中,凡屬「需要編輯權限」的動作都會特別標註。

## 5. 儀表板

儀表板是登入後的首頁,呈現球隊的整體狀態,**只供檢視,不需任何操作**。

內容包含:

- **YouTube 頻道**:點「前往頻道」可開啟球隊影片頻道。
- **關鍵數字**:現役選手人數、本學年度比賽次數、友誼賽次數。
- **訓練分布**:以雷達圖呈現各技術面向的訓練比重。右上角可切換統計區間(近 3 / 6 / 12 個月)。下方卡片列出各分類的訓練動作與次數。
- **戰績總覽**:本學年度各場比賽的名次與勝負明細。
- **近 5 場**:最新 5 個賽事大項目(含友誼賽)。

> 畫面右上角的標籤顯示目前統計的「學年度」。

## 6. 行事曆

「行事曆」以 **月曆** 方式呈現每天的 **訓練** 與 **比賽**,方便一眼掌握當月行程。

> 此頁 **只供檢視與導覽**,事件的新增 / 修改仍在「訓練紀錄」「比賽紀錄」頁進行。資料即時整合自這兩個功能頁。

### 6.1 切換月份

- 標題列中央顯示目前的「年 / 月」。
- 用左右 **箭頭** 切換上 / 下個月;按 **本月** 可立即跳回當月(已在當月時此鈕停用)。

### 6.2 圖例與當月統計

月曆上方以顏色區分三種事件,並顯示當月各自的數量:

| 顏色 | 事件 |
|------|------|
| 藍色 | 訓練 |
| 深藍 | 比賽 |
| 黃色 | 友誼賽 |

### 6.3 檢視事件

- **今天** 的日期會以實心圓標記。
- **電腦版**:每個日期格直接列出當天事件的標籤(含圖示與名稱);訓練顯示地點、比賽顯示賽事名稱與對手。**點任一標籤** 會開啟唯讀的「詳情」視窗。
- **手機版**:日期格以 **彩色圓點** 表示當天有哪些事件(最多 3 點,更多以「+N」呈現)。**點某一天** 後,畫面下方的「議程」會列出該日所有事件的完整內容,點擊即可開啟詳情視窗。

### 6.4 事件詳情

點事件後彈出唯讀視窗:

- **訓練詳情**:日期、地點、該次訓練的所有訓練項目(依分類分組)、備註;按 **前往訓練紀錄** 可跳到該頁。
- **比賽詳情**:賽事名稱、類型、日期、地點、名次(分隊時顯示 A / B)、出賽人數、影片連結,以及 **當日對戰**(對手、比分、勝負);按 **前往比賽紀錄** 可跳到該頁。

> 跨越多天的賽事會在 **每一天** 各自出現,且只顯示「當天」的對戰;若當日不是賽事起始日,詳情視窗會額外標註起始日。

## 7. 陣容

「陣容」頁是球隊人員總覽,以頁籤切換 **選手 / 教練 / 球經** 三種身份;每個身份底下再依狀態分成 **現役 / 畢業 / 離隊** 三區(畢業、離隊預設收合,點標題可展開)。

### 7.1 檢視與搜尋

- **頁籤**:頂部以頁籤切換「選手 / 教練 / 球經」,各頁籤顯示對應人數,並會記住上次選擇。
- **搜尋**:在搜尋框輸入姓名、暱稱、背號或學號,清單即時過濾。
- **篩選**:用「系級」「狀態」下拉縮小範圍;選手頁籤額外提供「位置」與「重複號碼」按鈕。已套用的條件會以標籤列出,可逐一清除或「全部清除」。
- **排序**:右上可選擇依姓名、系級排序(選手頁籤額外可選背號、身高),並用箭頭鈕切換正序 / 倒序。
- **球隊統計**:頁面上方顯示當前身份的現役人數、畢業 / 離隊人數;選手頁籤額外顯示各位置人數分布。

### 7.2 比較球員 *(僅選手頁籤)*

1. 在選手卡片右上角點 **天秤圖示**(或選取卡片後按空白鍵)將球員加入比較,最多 4 位。
2. 畫面下方出現比較浮動列,選滿 2 位以上後按 **比較**。
3. 彈出視窗以表格並列各球員的背號、位置、身高、系級等資料(身高最高者會被標示)。

### 7.3 匯出名單

點右上 **匯出** 按鈕,可將 **目前頁籤的篩選結果** 下載成 CSV 檔(可用 Excel 開啟)。教練 / 球經的 CSV 會省略背號、位置、身高與慣用手欄位。

### 7.4 新增人員　*(需選手編輯權限)*

1. 切換到要新增的頁籤(選手 / 教練 / 球經),點右上 **新增 + 該身份**。
2. 填寫資料:
   - **身份**(選手 / 教練 / 球經;進入後可再切換)
   - **姓名**(必填)
   - 暱稱(選填,最多 32 字)
   - 學號(選填,需唯一)
   - 生日(選填)
   - 系級(例:110)
   - **狀態**(現役 / 畢業 / 離隊)
   - 備註

   選擇「選手」時還會出現:背號(1–99)、身高(公分)、**位置**(可多選,見[附錄](#16-附錄名詞與代碼對照))、慣用手(左 / 右);切回教練 / 球經則隱藏並在儲存時清空。
3. 按 **儲存**,完成後回到陣容清單。

### 7.5 編輯人員　*(需選手編輯權限)*

點任一卡片,或卡片右上的 **鉛筆圖示**,即可進入編輯畫面;修改後按 **儲存**。
編輯畫面上方會顯示「最後更新者」與時間。

### 7.6 永久刪除人員　*(需「永久刪除選手」特殊權限)*

在編輯畫面右下角的 **刪除此選手 / 教練 / 球經** 按鈕,會將該人員與其所有相關紀錄 **永久移除,無法復原**,請審慎使用。一般情況建議改用「狀態:離隊 / 畢業」保留歷史資料。

> 若該球員有任何 **哭哭榜紀錄**(身為哭者或加分者),系統會 **阻止永久刪除**,以保護排行榜的歷史正確性。此時請改用「狀態:離隊 / 畢業」。

## 8. 訓練紀錄

「訓練紀錄」頁列出每一次訓練的卡片,依日期呈現。

### 8.1 檢視

- 每張卡片顯示日期、地點、訓練項目數量,以及各分類的項目數標籤。
- **點卡片可展開**,查看該次訓練選用的所有訓練項目(依分類分組)。
- 上方可用搜尋框(搜尋地點或備註)與「地點」下拉做篩選。

### 8.2 新增訓練　*(需訓練紀錄編輯權限)*

1. 點右上 **新增訓練**。
2. 填寫:
   - **日期**(必填)
   - 地點
   - **訓練項目**:從項目選擇器勾選本次要進行的項目。
   - 備註
3. 按 **儲存**。

### 8.3 編輯 / 刪除訓練　*(需訓練紀錄編輯權限)*

- 在卡片上點 **鉛筆圖示** 進入編輯;修改後按 **儲存**。
- 編輯畫面右下的 **刪除訓練** 會一併刪除該次訓練所選的項目關聯(不影響「訓練項目」項目庫本身)。

## 9. 比賽紀錄

「比賽紀錄」頁以賽事為單位,記錄每場賽事的對戰結果、出賽名單與比分。

### 9.1 檢視

- 每張賽事卡片顯示日期、學年、賽事類型(比賽 / 友誼賽)、名次、場數、出賽人數,以及一個 **戰績圓環**(勝 / 敗 / 平比例)。
- 若該賽事為 **分隊出賽**,會分別顯示 A 隊、B 隊的名次與戰績。
- **點卡片可展開**,查看出賽名單(依位置分組)與每一場對戰的比分細節(含各局比分)。
- 卡片若附影片連結,點「影片」可另開觀看。
- 上方篩選列可依 **學年**、**類型**(全部 / 比賽 / 友誼賽)以及關鍵字(對手、賽事名稱、地點)過濾。

### 9.2 新增比賽　*(需比賽紀錄編輯權限)*

1. 點右上 **新增比賽**。
2. 填寫賽事基本資料:賽事名稱、日期、類型、地點、影片網址、名次等。
3. 視需要設定是否 **分隊出賽**(A / B 隊)。
4. 加入 **出賽名單**(從球員中挑選)。
5. 逐場登錄 **對戰紀錄**:對手、總比分、各局比分、勝負結果。
6. 按 **儲存**。

### 9.3 編輯 / 刪除比賽　*(需比賽紀錄編輯權限)*

在賽事卡片點 **鉛筆圖示** 進入編輯;刪除動作同樣在編輯畫面內。

## 10. 訓練項目

「訓練項目」是一個 **項目庫**,集中管理所有可在「訓練紀錄」中被選用的訓練動作。項目依分類(基礎、發球、接發球、舉球、攻擊、攔網、防守、體能)分組。

### 10.1 檢視與搜尋

- 用搜尋框搜尋名稱或描述(鍵盤按 `/` 可快速聚焦搜尋框)。
- 點分類標籤可只顯示該分類的項目。
- 打開 **顯示已停用** 開關可一併看到停用中的項目。
- 7 天內新建的項目會標示「新」。

### 10.2 新增項目　*(需訓練項目編輯權限)*

1. 點右上 **新增項目**(鍵盤按 `N` 亦可)。
2. 填寫 **名稱**(必填)、**分類**(必選)、描述。
3. 「啟用中」開關決定此項目是否出現在訓練紀錄的選單中。
4. 按 **儲存**。

### 10.3 編輯、複製、停用　*(需訓練項目編輯權限)*

- **編輯**:點項目或鉛筆圖示。
- **複製**:點 **複製圖示** 會以該項目內容為範本開新項目(名稱自動加「複本」)。
- **快速啟用 / 停用**:直接切換項目列右側的開關。
- **停用**:在編輯畫面點「停用此項目」。停用後 **不會出現在新訓練的選單**,但 **既有歷史紀錄仍保留**。

> 訓練項目採「停用」而非真正刪除,以保護過往訓練紀錄的完整性。

## 11. 哭哭榜

「哭哭榜」是球隊內部的趣味紀錄,用來追蹤誰哭了、誰「加分」(讓人哭的角色,反諷用法)、原因是什麼,並以排行榜呈現統計結果。**此頁採用「可看就可編」設計** — 只要選單上看得到「哭哭榜」,就能新增、修改、刪除任何紀錄,沒有額外的編輯權限門檻。

### 11.1 檢視

- 頂部四張卡片顯示 **總哭哭次數**、**哭王 TOP 3**(哭最多次的前三人)、**加分王 TOP 3**(加分最多次的前三人)、**經典組合 TOP 3**(同一對[哭者 ← 加分者]出現次數最多的前三組)。
- 下方為紀錄清單,每筆顯示日期、哭者、原因、加分者清單與備註;外部加分者會帶 **(外)** 標記。
- 可用 **哭者下拉** 與 **加分者下拉** 兩個篩選器縮小範圍。這兩個下拉的選項來自 **實際出現在紀錄中的人**(包含已離隊 / 畢業的球員,以及外部加分者),而非目前陣容。

### 11.2 新增紀錄

1. 點右上 **新增哭哭** 按鈕,會 **跳出視窗** 供填寫:
   - **日期**(預設今天)
   - **哭哭的人**(單選,必填)
   - **原因**(必填,最多 256 字)
   - **加分者**(可多選、可空;哭者本人會自動排除)
     - **球員**:於網格直接點選。清單 **包含畢業 / 離隊球員**(會以 (畢) / (離) 標記,排序為現役在前),方便回填舊事件
     - **外部加分者**(非球員,如「對手」「教練」「家人」):於最下方輸入框打字,按 **Enter** 或 **加入** 鈕加入。最多 64 字,同一筆紀錄不可重複加入同一個名字
   - **備註**(選填)
2. 按 **新增**。可用 `Ctrl/⌘ + S` 快速儲存,或按 **取消** 關閉視窗。
3. **最近常用原因** 會出現在原因欄位下方的快速按鈕,點一下即可填入。

### 11.3 編輯 / 刪除

- 點清單任一筆右上的 **鉛筆圖示** 會以相同的視窗開啟該筆內容;修改後按 **儲存變更**。
- 刪除可從清單上的 **垃圾桶圖示** 或編輯視窗左下角的 **刪除** 進行,刪除前會跳出確認視窗,**刪除後無法復原**。

### 11.4 排行榜計算方式

頂部三張 TOP 3 卡片的計算規則:

| 榜單 | 計算方式 |
|------|----------|
| 哭王 | 該球員作為「哭哭的人」出現的紀錄筆數 |
| 加分王 | 該球員(或外部名字)作為「加分者」出現的「不同事件」筆數(同一筆只算一次) |
| 經典組合 | 同一對 [哭者 ← 加分者] 出現的次數 |

> 球員若有任何哭哭紀錄(身為哭者或球員加分者),便 **不能從陣容中永久刪除**,以保護排行榜的歷史正確性。請改用「狀態:離隊 / 畢業」。外部加分者僅是純文字,不涉及球員紀錄。

## 13. 使用者管理

「使用者管理」頁管理可登入系統的帳號。

> **重要**:只有超級管理員 **YUANHE** 能執行新增 / 編輯 / 停用 / 刪除;其他人即使能看到此頁,也僅能 **檢視清單**。

### 13.1 檢視

- 上方有「總計 / 啟用 / 停用 / Admin」統計卡,點卡片可快速套用對應篩選。
- 可用搜尋(帳號 / 顯示名稱 / Email)、角色、狀態做篩選。
- 表頭可點選切換排序。

### 13.2 新增使用者　*(僅 YUANHE)*

1. 點右上 **新增使用者**。
2. 填寫:
   - **帳號**(必填,僅英數,至少 3 字;`YUANHE` 為保留字不可使用)
   - 顯示名稱、Email
   - **角色**(必選)
   - **密碼**(必填,至少 8 字;畫面會顯示密碼強度)
3. 按 **儲存**。

### 13.3 編輯使用者　*(僅 YUANHE)*

點清單中任一列開啟編輯視窗,可修改顯示名稱、Email、角色;勾選「變更密碼」可重設該使用者的密碼。
**帳號建立後不可變更。**

### 13.4 啟用 / 停用、刪除　*(僅 YUANHE)*

- 用清單列上的 **電源圖示** 啟用 / 停用帳號;停用後該帳號無法登入。
- **垃圾桶圖示** 為刪除,刪除無法復原。
- 將角色變更為 / 自 Admin 時,系統會跳出二次確認。
- 超級管理員 YUANHE、以及「自己正在使用的帳號」會被保護,無法被停用或刪除。

## 14. 角色管理

「角色管理」頁設定每個角色「能看到哪些頁面、能執行哪些動作」。

### 14.1 版面

- **左側**:角色清單,顯示每個角色的使用人數、權限數、頁面數。系統內建角色會標「系統」。
- **右側**:選取角色後的編輯區。

### 14.2 編輯角色

1. 從左側點選一個角色(或按 **+** 新增角色)。
2. 設定 **名稱** 與 **描述**(系統角色名稱不可改)。
3. **可看到的頁面**:點選要開放給此角色的頁面。
4. **編輯權限**:開啟後該角色可對對應資源做新增 / 修改 / 刪除。
5. **特殊權限**:破壞性或系統管理動作(如「永久刪除選手」「使用者管理」「角色管理」),授權前請特別確認。
6. 按 **儲存**。

> - 開啟某項「編輯權限」時,系統會 **自動勾上對應頁面**(沒有頁面權限,編輯權限無從使用)。
> - 「全選 / 全清」可一鍵套用或清除所有頁面與權限。
> - 「哭哭榜」只有「頁面權限」可設,沒有獨立的編輯權限 — 開放該頁即等於開放新增 / 修改 / 刪除。

### 14.3 刪除角色

- 系統內建角色 **不可刪除**。
- 自訂角色若仍有使用者使用,**需先把那些使用者改派到其他角色** 才能刪除。

## 15. 常見問題 FAQ

**Q1. 為什麼我看不到某個選單(例如「使用者」)?**
側邊選單只顯示你的角色被允許的頁面。若需要該頁面,請聯絡管理員調整角色權限。

**Q2. 為什麼頁面上沒有「新增 / 編輯」按鈕?**
代表你只有該頁的檢視權限。需要編輯權限請聯絡管理員。

**Q3. 我突然被登出了。**
系統閒置滿 5 分鐘會自動登出,屬正常的安全保護。重新登入即可。

**Q4. 帳號忘記密碼怎麼辦?**
請聯絡超級管理員 YUANHE,於「使用者管理」中為你重設密碼。

**Q5. 進到「無權限」頁面?**
表示你嘗試開啟的頁面未對你的角色開放。回到儀表板或聯絡管理員。

**Q6. 停用的訓練項目,以前的訓練紀錄會消失嗎?**
不會。停用只是讓項目不再出現在新訓練的選單中,既有歷史紀錄完整保留。

**Q7. 不小心把人員設成「離隊」?**
進入「陣容」找到該人員、進入編輯畫面,把「狀態」改回「現役」並儲存即可。

**Q8. 為什麼建議用「離隊 / 畢業」而不是刪除人員?**
「永久刪除」會連同該球員的歷史比賽、訓練紀錄一併移除且無法復原;改狀態則可保留所有歷史資料。

**Q9. 行事曆上的訓練 / 比賽可以直接修改嗎?**
不行。行事曆只供檢視與導覽,點事件後可按「前往訓練紀錄 / 前往比賽紀錄」到對應頁面修改。

**Q10. 為什麼有的球員無法永久刪除?**
若該球員有哭哭榜紀錄(身為哭者或加分者),系統會阻止永久刪除以保護排行榜。請改用「狀態:離隊 / 畢業」。
