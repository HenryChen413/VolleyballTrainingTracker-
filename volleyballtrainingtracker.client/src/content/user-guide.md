## 1. 系統簡介

「高醫醫學女排‧排球訓練紀錄」是一套網頁版的球隊管理系統,協助教練團記錄球員名單、每次訓練的內容、比賽戰績,並以圖表呈現球隊整體狀態。

- **使用方式**:用瀏覽器開啟系統網址即可,無須安裝任何軟體。
- **建議瀏覽器**:Chrome、Edge、Safari 等較新版本的瀏覽器。
- **裝置支援**:電腦、平板、手機皆可使用,版面會自動依螢幕大小調整。
- **資料範圍**:本系統管理單一支球隊的資料。

## 2. 登入與登出

### 2.1 登入

1. 開啟系統網址,會看到「登入帳號」畫面。
2. 在 **帳號** 欄位輸入你的帳號(僅限英文與數字,輸入時會自動轉成大寫)。
3. 在 **密碼** 欄位輸入密碼。
4. 按 **登入** 按鈕。
5. 登入成功後會自動進入「儀表板」。

> 若帳號或密碼錯誤,畫面會顯示紅色提示訊息。帳號需由管理員預先建立,無法自行註冊。

> 系統會記錄你 **每次成功登入的時間**,供管理員查看。

### 2.2 自動登出(閒置保護)

為保護資料安全,若 **連續 5 分鐘沒有任何操作**(滑鼠、鍵盤、捲動皆算),系統會自動登出並回到登入頁。重新登入即可繼續使用。

### 2.3 登出

點畫面 **右上角的登出圖示**(向右箭頭),即可手動登出。

## 3. 介面導覽

### 3.1 整體版面

| 區域 | 位置 | 說明 |
|------|------|------|
| 側邊選單 | 電腦版畫面左側 | 各功能頁的入口 |
| 頂部列 | 畫面最上方 | 顯示目前位置(麵包屑)、深淺色切換、帳號、登出 |
| 底部分頁列 | 手機版畫面下方 | 手機版的主要功能快捷列 |

### 3.2 在不同裝置上的差異

- **電腦版**:左側固定選單。可點選單最下方的「收合側欄」把選單縮成只有圖示,騰出更多空間。
- **手機/平板版**:選單收進左上角的 **☰ 圖示**,點開為抽屜式選單;常用功能也會出現在畫面下方的分頁列。

### 3.3 深色 / 淺色模式

點頂部列的 **主題切換圖示** 可在淺色與深色佈景間切換,設定會被記住。

### 3.4 選單只顯示你有權限的項目

側邊選單只會列出 **你的角色被允許看到的頁面**。若某位使用者看不到某個選單,通常是角色權限未開放,屬正常現象(見[第 4 章](#4-角色與權限))。

## 4. 角色與權限

系統會依你的身份開放不同功能,你看到的畫面只會包含 **你能用的部分**:

- **側邊選單** 只列出你有權限進入的頁面。
- 在某些頁面,若你沒有編輯權限,畫面上的 **「新增 / 編輯 / 刪除」按鈕會自動隱藏**,你仍可正常瀏覽內容。

> 若你需要某個看不到的選單,或某頁缺少操作按鈕,通常是該功能尚未對你開放,屬正常現象 — 請聯絡 **系統管理員** 調整。

## 5. 儀表板

儀表板是登入後的首頁,彙整球隊的整體狀態與近期動態,**只供檢視,不需任何操作**。畫面右上角:

- **學年度標籤**:顯示目前統計所依據的學年度。
- **使用說明** 按鈕:點開即在視窗中彈出本說明文件,隨時可查閱操作方式。

內容由上而下包含:

### 5.1 社群連結

一張卡片提供兩個官方社群入口,點擊於新分頁開啟:

- **YouTube 頻道**:球隊影片頻道。
- **Instagram**:球隊 IG 動態。

### 5.2 關鍵數字

以數字卡呈現球隊重點指標:

- **現役選手**:現役選手人數;副標另顯示現役 **教練 / 球經** 人數。
- **賽事統計**:單張卡片內分兩行顯示本學年度的 **比賽(Official)** 與 **友誼賽** 場次數。
- **贊助榜** *(有開放「隊費贊助」且已有贊助資料時才顯示)*:以金 / 銀 / 銅標示累計金額 **前三名** 的贊助者(含背號、顯示名稱、身分與金額)。

### 5.3 哭哭榜 TOP 3 *(僅在你有「哭哭榜」頁面權限時顯示)*

兩張卡片並列,分別呈現 **哭哭王 TOP 3** 與 **加分王 TOP 3**:

- 每列顯示名次、姓名與次數;前三名以金 / 銀 / 銅色標示,加分王的外部加分者標 **(外)**、球員顯示背號。
- 採 **並列名次**(同分同名次、下一名次跳號);同一名次並列超過 2 人時僅列前 2 位,其餘收合為「並列第 N・還有 X 人 →」,點擊可跳至「哭哭榜」頁。
- 尚無資料時顯示「尚無資料」。

### 5.4 本月壽星

列出本月過生日的 **現役隊員**(選手在前、教練 / 球經在後,同身份再依日期排序):

- 每張卡片顯示姓名(或暱稱)、背號(選手)或教練 / 球經標籤、生日月日,以及當天滿幾歲。
- **當天生日** 的隊員會以 🎂 標記並以主色強調。
- 本月若無人過生日,顯示「本月沒有壽星」。

### 5.5 訓練分布

以 **雷達圖** 呈現各技術面向的訓練比重(不含基礎、體能):

- 右上角可切換統計區間(**近 3 / 6 / 12 個月**)。
- 下方卡片逐一列出各分類的次數、占比與該分類常用的訓練動作。
- 若期間另有「基礎」「體能」訓練,會在最下方附註其次數(此兩類不計入雷達圖比重)。

### 5.6 戰績總覽

呈現本學年度各場 **比賽(Official)** 的名次與勝負明細:

- 上方為各賽事的名次卡(分隊出賽時分別顯示 A / B 隊名次,未評定則標「未評定」)。
- 下方逐場列出對手、比分與勝 / 敗 / 平。
- 本學年度尚無比賽時顯示「本學年度尚無比賽紀錄」。

### 5.7 近 5 場

列出最新 5 個賽事大項目(**含友誼賽**),顯示類型、日期、賽事名稱、地點與名次;**點任一筆可跳至「比賽紀錄」頁**。

## 6. 行事曆

「行事曆」以 **月曆** 方式呈現每天的 **訓練** 與 **比賽**,方便一眼掌握當月行程。

> 此頁 **只供檢視與導覽**,事件的新增 / 修改仍在「訓練紀錄」「比賽紀錄」頁進行。

### 6.1 切換月份

- 標題列中央顯示目前的「年 / 月」。
- 用左右 **箭頭** 切換上 / 下個月;按 **本月** 可立即跳回當月(已在當月時此鈕停用)。

### 6.2 圖例與當月統計

月曆上方以顏色區分三種事件,並顯示當月各自的數量:

| 顏色 | 事件 |
|------|------|
| 藍色 | 訓練 |
| 深藍 | 比賽 |
| 黃色 | 友誼賽 |

### 6.3 檢視事件

- **今天** 的日期會以實心圓標記。
- **電腦版**:每個日期格直接列出當天事件的標籤(含圖示與名稱);訓練顯示地點、比賽顯示賽事名稱與對手。**點任一標籤** 會開啟唯讀的「詳情」視窗。
- **手機版**:日期格以 **彩色圓點** 表示當天有哪些事件(最多 3 點,更多以「+N」呈現)。**點某一天** 後,畫面下方的「議程」會列出該日所有事件的完整內容,點擊即可開啟詳情視窗。

### 6.4 事件詳情

點事件後彈出唯讀視窗:

- **訓練詳情**:日期、地點、該次訓練的所有訓練項目(依分類分組)、備註;按 **前往訓練紀錄** 可跳到該頁。
- **比賽詳情**:賽事名稱、類型、日期、地點、名次(分隊時顯示 A / B)、出賽人數、影片連結,以及 **當日對戰**(對手、比分、勝負);按 **前往比賽紀錄** 可跳到該頁。

> 跨越多天的賽事會在 **每一天** 各自出現,且只顯示「當天」的對戰;若當日不是賽事起始日,詳情視窗會額外標註起始日。

## 7. 陣容

「陣容」頁是球隊人員總覽,以頁籤切換 **選手 / 教練 / 球經** 三種身份;每個身份底下再依狀態分成 **現役 / 畢業 / 離隊** 三區(畢業、離隊預設收合,點標題可展開)。

### 7.1 檢視與搜尋

- **頁籤**:頂部以頁籤切換「選手 / 教練 / 球經」,各頁籤顯示對應人數,並會記住上次選擇。
- **搜尋**:在搜尋框輸入姓名、暱稱、背號或學號,清單即時過濾。
- **篩選**:用「系級」「狀態」下拉縮小範圍;選手頁籤額外提供「位置」與「重複號碼」按鈕。已套用的條件會以標籤列出,可逐一清除或「全部清除」。
- **排序**:右上可選擇依姓名、系級排序(選手頁籤額外可選背號、身高),並用箭頭鈕切換正序 / 倒序。
- **球隊統計**:頁面上方顯示當前身份的現役人數、畢業 / 離隊人數;選手頁籤額外顯示各位置人數分布。

### 7.2 比較球員 *(僅選手頁籤)*

1. 在選手卡片右上角點 **天秤圖示**(或選取卡片後按空白鍵)將球員加入比較,最多 4 位。
2. 畫面下方出現比較浮動列,選滿 2 位以上後按 **比較**。
3. 彈出視窗以表格並列各球員的背號、位置、身高、系級等資料(身高最高者會被標示)。

### 7.3 匯出名單

點右上 **匯出** 按鈕,可將 **目前頁籤的篩選結果** 下載成 CSV 檔(可用 Excel 開啟)。教練 / 球經的 CSV 會省略背號、位置、身高與慣用手欄位。

### 7.4 新增人員

1. 切換到要新增的頁籤(選手 / 教練 / 球經),點右上 **新增 + 該身份**。
2. 填寫資料:
   - **身份**(選手 / 教練 / 球經;進入後可再切換)
   - **姓名**(必填)
   - 暱稱(選填,最多 32 字)
   - 學號(選填,需唯一)
   - 生日(選填)
   - 系級(例:110)
   - **狀態**(現役 / 畢業 / 離隊)
   - 備註

   選擇「選手」時還會出現:背號(1–99)、身高(公分)、**位置**(可多選,見[附錄](#16-附錄名詞與代碼對照))、慣用手(左 / 右);切回教練 / 球經則隱藏並在儲存時清空。
3. 按 **儲存**,完成後回到陣容清單。

### 7.5 編輯人員

點任一卡片,或卡片右上的 **鉛筆圖示**,即可進入編輯畫面;修改後按 **儲存**。
編輯畫面上方會顯示「最後更新者」與時間。

### 7.6 永久刪除人員

在編輯畫面右下角的 **刪除此選手 / 教練 / 球經** 按鈕,會將該人員與其所有相關紀錄 **永久移除,無法復原**,請審慎使用。一般情況建議改用「狀態:離隊 / 畢業」保留歷史資料。

> 若該球員有 **哭哭榜紀錄**,系統會阻止永久刪除,此時請改用「狀態:離隊 / 畢業」。

## 8. 訓練紀錄

「訓練紀錄」頁列出每一次訓練的卡片,依日期呈現。

### 8.1 檢視

- 每張卡片顯示日期、地點、訓練項目數量,以及各分類的項目數標籤。
- **點卡片可展開**,查看該次訓練選用的所有訓練項目(依分類分組)。
- 上方可用搜尋框(搜尋地點或備註)與「地點」下拉做篩選。

### 8.2 新增訓練

1. 點右上 **新增訓練**。
2. 填寫:
   - **日期**(必填)
   - 地點
   - **訓練項目**:從項目選擇器勾選本次要進行的項目。
   - 備註
3. 按 **儲存**。

### 8.3 編輯 / 刪除訓練

- 在卡片上點 **鉛筆圖示** 進入編輯;修改後按 **儲存**。
- 編輯畫面右下的 **刪除訓練** 會一併刪除該次訓練所選的項目關聯(不影響「訓練項目」項目庫本身)。

## 9. 比賽紀錄

「比賽紀錄」頁以賽事為單位,記錄每場賽事的對戰結果、出賽名單與比分。

### 9.1 檢視

- 每張賽事卡片顯示日期、學年、賽事類型(比賽 / 友誼賽)、名次、場數、出賽人數,以及一個 **戰績圓環**(勝 / 敗 / 平比例)。
- 若該賽事為 **分隊出賽**,會分別顯示 A 隊、B 隊的名次與戰績。
- **點卡片可展開**,查看出賽名單(依位置分組)與每一場對戰的比分細節(含各局比分)。
- 卡片若附影片連結,點「影片」可另開觀看。
- 上方篩選列可依 **學年**、**類型**(全部 / 比賽 / 友誼賽)以及關鍵字(對手、賽事名稱、地點)過濾。

### 9.2 新增比賽

1. 點右上 **新增比賽**。
2. 填寫賽事基本資料:賽事名稱、日期、類型、地點、影片網址、名次等。
3. 視需要設定是否 **分隊出賽**(A / B 隊)。
4. 加入 **出賽名單**(從球員中挑選)。
5. 逐場登錄 **對戰紀錄**:對手、總比分、各局比分、勝負結果。
6. 按 **儲存**。

### 9.3 編輯 / 刪除比賽

在賽事卡片點 **鉛筆圖示** 進入編輯;刪除動作同樣在編輯畫面內。

## 10. 訓練項目

「訓練項目」是一個 **項目庫**,集中管理所有可在「訓練紀錄」中被選用的訓練動作。項目依分類(基礎、發球、接發球、舉球、攻擊、攔網、防守、體能)分組。

### 10.1 檢視與搜尋

- 用搜尋框搜尋名稱或描述(鍵盤按 `/` 可快速聚焦搜尋框)。
- 點分類標籤可只顯示該分類的項目。
- 打開 **顯示已停用** 開關可一併看到停用中的項目。
- 7 天內新建的項目會標示「新」。

### 10.2 新增項目

1. 點右上 **新增項目**(鍵盤按 `N` 亦可)。
2. 填寫 **名稱**(必填)、**分類**(必選)、描述。
3. 「啟用中」開關決定此項目是否出現在訓練紀錄的選單中。
4. 按 **儲存**。

### 10.3 編輯、複製、停用

- **編輯**:點項目或鉛筆圖示。
- **複製**:點 **複製圖示** 會以該項目內容為範本開新項目(名稱自動加「複本」)。
- **快速啟用 / 停用**:直接切換項目列右側的開關。
- **停用**:在編輯畫面點「停用此項目」。停用後 **不會出現在新訓練的選單**,但 **既有歷史紀錄仍保留**。

> 訓練項目採「停用」而非真正刪除,以保護過往訓練紀錄的完整性。

## 11. 哭哭榜

「哭哭榜」是球隊內部的趣味紀錄,用來追蹤誰哭了、誰「加分」(讓人哭的角色,反諷用法)、原因是什麼,並以排行榜呈現統計結果。

### 11.1 檢視

- 頂部四張卡片顯示 **總哭哭次數**、**哭哭王 TOP 3**(哭最多次的前三人)、**加分王 TOP 3**(加分最多次的前三人)、**經典組合 TOP 3**(同一對[哭者 ← 加分者]出現次數最多的前三組)。TOP 3 採 **並列名次**:同分者同名次(如兩人並列第一顯示 1、1、3;並列季軍時會一併列出第四列)。
- 下方為紀錄清單,每筆顯示日期、哭者、原因、加分者清單與備註;外部加分者會帶 **(外)** 標記。
- 可用 **哭者下拉** 與 **加分者下拉** 兩個篩選器縮小範圍。這兩個下拉的選項來自 **實際出現在紀錄中的人**(包含已離隊 / 畢業的球員,以及外部加分者),而非目前陣容。

### 11.2 新增紀錄

1. 點右上 **新增哭哭** 按鈕,會 **跳出視窗** 供填寫:
   - **日期**(預設今天)
   - **哭哭的人**(單選,必填;下拉依 **教練 → 現役 → 畢業 → 球經 → 離隊** 分組)
   - **原因**(必填,最多 256 字)
   - **加分者**(可多選、可空;**可選哭者自己** — 有時是自己把自己弄哭)
     - **球員**:於網格直接點選,依 **教練 / 現役 / 畢業 / 球經 / 離隊** 分組顯示;哭者本人會標 **自己**,方便回填舊事件
     - **外部加分者**(非球員,如「對手」「教練」「家人」):於最下方輸入框打字,按 **Enter** 或 **加入** 鈕加入。最多 64 字,同一筆紀錄不可重複加入同一個名字
   - **備註**(選填)
2. 按 **新增**。可用 `Ctrl/⌘ + S` 快速儲存,或按 **取消** 關閉視窗。
3. **最近常用原因** 會出現在原因欄位下方的快速按鈕,點一下即可填入。

### 11.3 編輯 / 刪除

- 點清單任一筆右上的 **鉛筆圖示** 會以相同的視窗開啟該筆內容;修改後按 **儲存變更**。
- 刪除可從清單上的 **垃圾桶圖示** 或編輯視窗左下角的 **刪除** 進行,刪除前會跳出確認視窗,**刪除後無法復原**。

## 12. 留言板

「留言板」是隊內的公告與交流牆,採 **貼文 + 回覆** 兩層式設計,可發文、回覆、按讚(❤)。

> 你可以 **發文、回覆、按讚,並編輯 / 刪除自己發布的內容**。**刪除他人貼文 / 回覆、置頂貼文** 屬管理員功能。

### 12.1 檢視

- 貼文依時間 **由新到舊** 排列;**置頂貼文** 永遠排在最前,並以特殊底色與「置頂」標籤標示。
- 每則貼文顯示 **作者、發布時間、內容、❤ 數、回覆數**;曾被編輯過會標註「(已編輯)」。
- 發布時間以 **相對時間** 呈現(如「剛剛」「5 分鐘前」「3 小時前」「2 天前」,超過 7 天改顯示日期)。
- 清單 **每頁 20 則**,下方以「上一頁 / 下一頁」翻頁。

### 12.2 發文

1. 在頁面上方的輸入框輸入內容(最多 **2000 字**,下方有即時字數計)。
2. 按 **發布**,或用 `Ctrl/⌘ + Enter` 快速送出。
3. 發布後新貼文會出現在 **第一頁最上方**。

### 12.3 按讚與回覆

- 點貼文下方的 **愛心圖示** 可按讚 / 取消讚(再按一次即取消);旁邊數字為總讚數。
- 點 **對話框圖示** 展開回覆輸入框,輸入回覆(最多 **1000 字**)後按 **送出**(或 `Ctrl/⌘ + Enter`)。回覆會列於該貼文下方。

### 12.4 編輯 / 刪除

- **自己的貼文 / 回覆**:用 **鉛筆圖示** 編輯、**垃圾桶圖示** 刪除。
- **置頂 / 取消置頂**　*(管理員功能)*:點貼文右上的 **圖釘圖示**。
- **刪除他人的貼文 / 回覆**　*(管理員功能)*:對他人內容也會出現垃圾桶圖示。
- 刪除前會跳出確認視窗,**刪除後無法復原**。

## 13. 隊費贊助

「隊費贊助」用來記錄並感謝贊助隊費的人,並以 **芳名榜** 呈現每位贊助者的累計金額排名。贊助者可能是 **已畢業、不在現役陣容** 的學長姊,因此採「贊助者名冊」設計,不限定於陣容。

> 你可以 **瀏覽** 芳名榜與所有贊助紀錄。**新增 / 修改 / 刪除** 贊助者與紀錄因涉及金錢,屬教練 / 管理員功能,一般成員不會看到相關按鈕。

### 13.1 畫面組成

- 頂部三張卡片顯示 **累計贊助總額**、**贊助筆數**、**贊助人數**。
- **贊助芳名榜**:**前三名** 以獎台呈現,其餘贊助者以 **感謝牆** 卡片列出,皆依累計金額排序。
- **贊助紀錄**:逐筆列出日期、贊助者、金額與用途,可用右上下拉依贊助者篩選。

### 13.2 贊助者名冊

贊助者以名冊為單位,確保同一人多次贊助能正確累計。按右上 **管理贊助者** 開啟名冊視窗:

- **連結人員**(選填):若贊助者是現役 / 畢業 / 離隊人員,可從下拉選取,系統會自動帶入姓名;陣容外的學長姊 / 家長 / 廠商則 **留空**。
- **顯示名稱**(必填):芳名榜與紀錄上呈現的名稱。
- **身分**:學姊 / 學長 / 家長 / 廠商 / 其他。
- 已有贊助紀錄的贊助者 **無法直接刪除**,需先刪除其紀錄,以保護芳名榜的正確性。

### 13.3 新增一筆贊助

1. 按右上 **新增贊助** 開啟視窗。
2. 選擇 **贊助者**(若名冊尚無此人,先按「管理贊助者」新增)。
3. 填寫 **金額**(正整數)與 **日期**。
4. 視需要填 **用途**(如隊服、場租、報名費)與 **備註**,按 **新增 / 儲存變更**(可用 Ctrl/⌘+S)。

## 14. 我的帳號

「我的帳號」頁讓你管理自己的個人資料與密碼。點頂部列的 **人形圖示** 進入。

### 14.1 基本資料

- 可修改 **Email** 與 **顯示名稱**。
- **帳號無法自行修改**。
- 修改後按 **儲存**。

### 14.2 變更密碼

1. 輸入 **目前密碼**(用於驗證身分)。
2. 輸入 **新密碼**(至少 8 個字)。
3. 再次輸入新密碼確認。
4. 按 **更新密碼**。

## 15. 常見問題 FAQ

**Q1. 為什麼我看不到某個選單,或頁面上沒有「新增 / 編輯」按鈕?**
代表該功能尚未對你開放,或你只有檢視權限。需要時請聯絡系統管理員。

**Q2. 我突然被登出了。**
系統閒置滿 5 分鐘會自動登出,屬正常的安全保護。重新登入即可。

**Q3. 帳號忘記密碼怎麼辦?**
請聯絡系統管理員為你重設密碼。

**Q4. 停用的訓練項目,以前的訓練紀錄會消失嗎?**
不會。停用只是讓項目不再出現在新訓練的選單中,既有歷史紀錄完整保留。

**Q5. 不小心把人員設成「離隊」?**
進入「陣容」找到該人員、進入編輯畫面,把「狀態」改回「現役」並儲存即可。

**Q6. 為什麼建議用「離隊 / 畢業」而不是刪除人員?**
「永久刪除」會連同該人員的歷史比賽、訓練紀錄一併移除且無法復原;改狀態則可保留所有歷史資料。

**Q7. 行事曆上的訓練 / 比賽可以直接修改嗎?**
不行。行事曆只供檢視與導覽,點事件後可按「前往訓練紀錄 / 前往比賽紀錄」到對應頁面修改。

**Q8. 為什麼有的球員無法永久刪除?**
若該球員有哭哭榜紀錄,系統會阻止永久刪除。請改用「狀態:離隊 / 畢業」。

**Q9. 為什麼我不能刪除別人的留言或置頂貼文?**
刪除他人貼文 / 回覆、以及置頂貼文屬管理員功能。一般成員只能管理自己發布的內容,如有需要請聯絡系統管理員。
